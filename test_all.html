4) 리스트 태그 (ul/ol/dl)

• ul (순서 없음)

  • 사과는 맛있다
  • 맛있으면 바바나 바나나는 길어
  • 길면 기차 기차는 빨라 빠르면 비행기

• ol (순서 있음)

  1. HTML 파일 만들기
  2. 여러가지 예제 코드 만들어보기
  3. Live Server로 확인하기

• dl (용어/설명)

HTML
웹페이지의 구조(뼈대)
CSS
웹페이지의 스타일(꾸미기)
JavaScript
웹페이지의 동작(반응)
